TankTrouble Skin Tools

Install guide · version {{version}} · an unofficial fan-made add-on by Bleed

Give your tank a new look

Skin Tools is a small, free add-on for Google Chrome (and Chrome-based browsers like Edge and Brave). It changes how tanks look, on your own screen only. Nobody else sees it, and the game plays exactly the same. It has no automation and no cheats.

Install itHow to use it

Install (about 3 minutes)

1

Download it from GitHub

Open the project's Releases page. Under Assets, click {{zip}}. Your browser downloads it (about 800 KB).

Source code (zip)
Source code (tar.gz)

You only need the first file, {{zip}}. The "Source code" files are for developers.

2

Unzip it

Windows: right-click the ZIP and choose Extract All…, then Extract.
Mac: double-click the ZIP.

You get a folder with START-HERE.html (this guide), extension (the add-on), skin-packs (three example skins) and about.

Keep the folder somewhere it will stay, like Documents. Chrome runs the add-on from this folder, so don't move or delete it.

3

Open Chrome's extensions page and switch on Developer mode

  1. Type chrome://extensions in the address bar and press Enter.
    Edge: edge://extensions · Brave: brave://extensions
  2. Switch on Developer mode (top right). Three new buttons appear.
4

Click “Load unpacked”

Click Load unpacked and choose the extension folder from step 2 (the one that contains manifest.json).

5

Open Skin Tools in TankTrouble

Go to tanktrouble.com. A small black Skins button appears in the bottom-right corner. Click it to open the panel. Drag the panel by its title bar to move it, and use the – button to fold it away.

Use it

6

Import a skin

In the panel click Manage skins, then Add a folder, and pick one folder inside skin-packs (for example golden-tank). Repeat for each skin you want. Skins from friends work the same way: a folder of PNG pictures and a skin.json file. You can also drag the files onto the panel. If a skin has a problem, the panel says which picture and what size it should be.

7

Choose a skin

Under Who wears it, leave My tank selected and pick a skin from the list. It changes right away. There is nothing else to press. Click the little picture to see it bigger.

8

Go back to the original look

  • Everything off, right now: flick the switch to Off. Turn it on again to bring your skins back.
  • Just your tank: choose Original look at the top of the skin list.
  • Forget who wears what: Advanced → Clear assignments. Your skins stay installed.
  • Delete a skin: Manage skins → the bin next to it.
  • Remove the add-on: chrome://extensions → Skin Tools → Remove.

Extras

Skins for other players. Everyone gives every tank the same skin. A player lets you search for one player by name and give just them a skin. Only you see it. 3D Shaders keeps each player's own colours and makes their tank look 3D.

Colours. Open Advanced to recolour the body, turret or treads of whoever you picked, or to show a skin as painted or tinted with each player's colour.

Good to know

  • Only on your screenSkins are drawn by your browser. Other players see their usual tanks.
  • Same gameNothing about play changes: same speed, same hitboxes, same bullets.
  • Nothing is sent anywhereNo account, no internet use, no tracking. Your skins are stored in your own browser.
  • UnofficialMade by fans; not made or supported by the makers of TankTrouble.

Something not working?

I don't see the Skins button

Reload the TankTrouble page. Check that Skin Tools is switched on in chrome://extensions, and that the address starts with https://tanktrouble.com.

There is no "Load unpacked" button

Switch on Developer mode in the top-right corner of chrome://extensions.

Chrome warns that it "can't verify where this extension comes from"

Chrome says this about add-ons that aren't from its web store when Developer mode is off. Keep Developer mode switched on. Skin Tools works only on tanktrouble.com and never uses the internet.

Chrome asks whether to keep "developer mode extensions"

Chrome can show this reminder when it starts, because the add-on is loaded from a folder. Choose to keep it. Skin Tools is not from the Chrome Web Store, so this is normal.

The add-on stopped working after I moved or deleted the folder

Chrome runs it from that folder. Put the folder back, or click Load unpacked again and choose the extension folder in its new place.

A skin won't install

The panel explains what's wrong, for example a picture with the wrong size or a missing file. Ask whoever made the skin for a fixed version.

My skins disappeared

They are stored by your browser for tanktrouble.com. Clearing that site's data, or playing in a private window, starts empty. Add them again from the skin-packs folder.

Something looks odd in the game

Flick the switch to Off: the game's own look comes back immediately. Turning it on again re-applies your skins.
